# 社会課題の根拠（説明ドキュメント 2-1・2-2 の材料）

取得日: 2026-11-06（深夜）。各数字は、出典のページ（または PDF）を開いて、該当の記述を確認したもの。確認できなかったものは「未確認」と書く。

## 想定ユーザーと課題（取り決め）

**日帰り〜1泊の旅行者（学生・若年層が中心）が、混雑で疲れ、穴場を探す時間もない。**
オーバーツーリズムは、その背景（社会の側の課題）として示す。

## 課題の筋道

1. **旅行者が、一部の地域・時間帯に集中している。** 訪日外国人は 2025 年に過去最多（4,268 万人）。国内旅行者も同じ有名な場所・同じ時間に重なる。
2. **その集中で、住民の生活と、旅行者の満足度への影響が懸念されている。** 国自身が、そう書いている（根拠 1）。
3. **旅行者は、混雑の情報が足りず、自力で避けにくい。** 混雑で困った人の 41% が「混雑や渋滞等の情報が発信されていない・情報量が不足」を挙げている（根拠 3）。
4. **若年層は、時間をかけずに旅先を決めたい傾向がある**（根拠 6）。穴場を探し回る時間は取りにくい。
5. **IntenTrip は、旅行者の側から、時間と場所を分けて回る旅程を、AI が複数案（注意点つき）で出し、人が理由を添えて選ぶ形で支える。**

## 説明ドキュメントでの使い方（案）

- **2-1 対象ユーザー**: 日帰り〜1 泊で、有名な観光地に行こうとする旅行者（学生・若年層が中心）。
- **2-2 課題と根拠**:
  1. 旅行者の集中は、過去最多の水準にある（根拠 2）。
  2. 国は、一部の地域や時間帯によっては、過度の混雑やマナー違反による地域住民の生活への影響や、旅行者の満足度低下への懸念が生じているとしている（根拠 1）。自治体も、市民と観光の棲み分けに取り組んでいる（根拠 4）。
  3. 一方、旅行者の側では、混雑で困った人の約 4 割が「情報不足」を挙げる（根拠 3）。サステナビリティ関連の問題（最大の要因は人混み）を理由に、行き先を避けた旅行者は少なくない（根拠 6）。
  4. 若年層は、時間をかけずに旅先を決める傾向がある（根拠 7）。
  5. だから、旅行者の側から、時間と場所を分けた旅程を、短時間で組めるようにする。

## 未確認・足りない根拠（正直に書く）

- **学生・若年層の旅行者が、国内で「混雑で疲れる」と感じる割合**を直接示す数字は、見つからなかった（根拠 3 は、訪日外国人の調査）。
- **「穴場を探す時間がない」ことを直接示す数字**は、見つからなかった（根拠 7 は、間接的）。
- **京都市の市民の意識調査の数字**（混雑で迷惑していると答えた割合など）は、資料の年度の対応が分からず、確認できなかった。京都市の「観光課題対策」の資料（`city.kyoto.lg.jp`）を、原資料で確かめる必要がある。
- 観光庁の資料に「需要の分散・平準化」という施策の語があるという検索結果の抜粋を見たが、原資料で確認できていない。使わない。

### 補う案（チームでできること）

- 学生 5 人ほどへの**簡単なヒアリング**: 「最近の旅行で、混雑がつらかったか」「穴場を調べるのに、どれくらい時間を使ったか」「旅程づくりで困ったこと」。**自分たちの調べとして、「5 人に聞いた」と、人数を正直に書く。**
- 上のヒアリングが済むまでは、**国・自治体の資料（根拠 1〜5）を主軸にし、若年層の数字（根拠 7）は補助にとどめる。**
